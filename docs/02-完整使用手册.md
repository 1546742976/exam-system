## 2. 密码和密钥

### 2.1 监考控制台密码

监考控制台地址：

```text
http://10.20.0.105:8888/exam/admin
```

密码保存在：

```text
/home/ckyf/ctest/exam-system/server/.env
```

查看命令：

```bash
grep '^CKYF_ADMIN_PASSWORD=' /home/ckyf/ctest/exam-system/server/.env
```

注意：这是**考试网关的监考控制台密码**，不是 HydroOJ 管理员账号密码。

### 2.2 修改监考密码

生成新密码：

```bash
python3 -c 'import secrets; print(secrets.token_urlsafe(24))'
```

编辑：

```bash
nano /home/ckyf/ctest/exam-system/server/.env
```

修改：

```text
CKYF_ADMIN_PASSWORD=新密码
```

重启网关：

```bash
sudo systemctl restart ckyf-exam-gateway
```

### 2.3 HydroOJ 管理员密码

HydroOJ 管理员账号密码在 HydroOJ 的用户系统中设置，不在 `server/.env` 中。

管理员访问：

```text
http://10.20.0.105:8888/
```

如果需要管理比赛，推荐流程：

1. 先打开 `http://10.20.0.105:8888/exam/admin` 登录监考密码；
2. 在同一浏览器打开 `http://10.20.0.105:8888/` 登录 HydroOJ 管理员；
3. 此时可以正常进入比赛管理和创建比赛页面。

### 2.4 学生账号

学生账号在 HydroOJ 中创建，由教师分配。

### 2.5 签名密钥

| 文件/变量 | 作用 |
|---|---|
| `server/.env` 中的 `CKYF_SIGN_KEY` | 视频切片签名共享密钥 |
| `client/config.json` 中的 `sign_key` | 必须与网关一致 |
| `server/keys/private.pem` | HydroOJ 插件签发考试令牌 |
| `server/keys/public.pem` | 网关/客户端验签公钥 |
| `client/keys/public.pem` | 客户端教师令牌验签公钥 |

严禁把 `server/.env` 和 `server/keys/private.pem` 发给学生。

## 4. 比赛配置

### 4.1 创建比赛

1. 登录监考控制台获得 `gw_admin` Cookie；
2. 登录 HydroOJ 管理员；
3. 进入比赛管理，创建比赛；
4. 设置比赛开始时间、结束时间和参赛权限；
5. 给测试学生账号报名，或确认比赛允许自由参加。

### 4.2 获取比赛 ID

打开比赛详情页，浏览器地址类似：

```text
http://10.20.0.105:8888/contest/6ae8a2cb33a087ceedc6824e
```

最后的：

```text
6ae8a2cb33a087ceedc6824e
```

就是比赛 ID。

### 4.3 配置网关比赛地址

编辑：

```bash
nano /home/ckyf/ctest/exam-system/server/.env
```

单场比赛填写比赛详情页的实际路径，例如：

```text
CKYF_CONTEST_URL=/contest/6ae8a2cb33a087ceedc6824e
```

如果你的 HydroOJ 路径是：

```text
/d/system/contest/<contest_id>
```

就填写完整实际路径：

```text
CKYF_CONTEST_URL=/d/system/contest/<contest_id>
```

不能只填比赛 ID，也不能漏掉 `/contest`。

保存后重启：

```bash
sudo systemctl restart ckyf-exam-gateway
```

### 4.4 校验配置

```bash
grep '^CKYF_CONTEST_URL=' /home/ckyf/ctest/exam-system/server/.env
```

学生登录后应进入该 URL，而不是 404。

## 5. 学生客户端部署

### 5.1 学生机要求

- Windows 10 1809+ 或 Windows 11，x64；
- WebView2 Evergreen Runtime x64；
- Python 3.12 / 3.13 建议版本；
- 能访问 `10.20.0.105:8888`；
- 不能访问外网；
- 不能直连 `10.20.0.105:8889`；
- 磁盘至少预留 2 GB。

### 5.2 安装依赖

```bat
cd client
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
```

### 5.3 开放教师抓图端口

学生机以管理员身份打开 PowerShell：

```powershell
New-NetFirewallRule `
  -DisplayName "ckyf exam client 34519" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 34519 `
  -Action Allow
```

### 5.4 启动客户端

```bat
cd client
.venv\Scripts\activate.bat
python main.py
```

填写：

```text
接口地址：10.20.0.105:8888
账号：HydroOJ 学生账号
密码：学生账号密码
```

流程：

```text
登录
→ 环境检测
→ 选择屏幕和摄像头
→ 下一步
→ 进入比赛页面
```

### 5.5 更新客户端后重算指纹

每次修改 `client/*.py` 后：

```bash
cd /home/ckyf/ctest/exam-system/server
. .venv/bin/activate
python tools/allowlist.py ../client
```

查看当前白名单：

```bash
python tools/allowlist.py ../client --show
```

## 8. 比赛当天流程

### 8.1 前一天

- 完成服务端 16/16 冒烟测试；
- 完成至少一台 Windows 学生机全流程测试；
- 确认教师截图和抽查正常；
- 重新打包学生客户端；
- 重新运行 `allowlist.py`；
- 备份当前数据库和密钥；
- 确认路由器 WAN 口不接外网。

### 8.2 开考前

```bash
sudo systemctl status ckyf-exam-gateway --no-pager
sudo pm2 list
ss -lntp | grep -E ':(80|8888|8889)\b'
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8888/exam/admin
```

检查：

- 比赛时间已到；
- 比赛路径 `CKYF_CONTEST_URL` 正确；
- 测试学生可登录；
- 学生机不能上外网；
- 学生机不能直连 8889；
- 路由器没有开启 AP 隔离/访问控制；
- 学生机 34519 放行。

### 8.3 考试中

- 控制台查看在线、静默、告警；
- 定期使用截图/抽查；
- 关注上传缺口；
- 不要随意重启网关或 HydroOJ；
- 如需重启，先记录时间和当前状态。

### 8.4 考试结束

1. 让学生端退出；
2. 停止考试网关，避免继续接收上传：
   ```bash
   sudo systemctl stop ckyf-exam-gateway
   ```
3. 备份：
   ```bash
   cd /home/ckyf/ctest/exam-system
   tar czf ~/exam-backup-$(date +%Y%m%d-%H%M).tgz \
     server/data \
     server/.env \
     server/config.json
   ```
   如果还需要保存视频，把 `server/data/uploads/` 一起单独打包。
4. 检查上传缺口和签名：
   ```bash
   cd server
   . .venv/bin/activate
   python tools/verify_sig.py "录制目录" "学生用户名" "sign_key"
   ```

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 学生端 NOT FOUND | `CKYF_CONTEST_URL` 错误 | 填浏览器中实际比赛路径并重启网关 |
| `/exam` 用 `curl -I` 返回 405 | 插件路由只接受 GET，HEAD 不支持 | 用 GET 测试，不是故障 |
| Caddy 返回 502 | 8888 网关未启动 | `sudo systemctl restart ckyf-exam-gateway` |
| 学生访问 8888 拒绝 | 网关未启动或监听地址错误 | 检查 `ss -lntp` 和 systemd 日志 |
| 学生能直连 8889 | HydroOJ 监听在 0.0.0.0 | 将 `server.host` 改为 `127.0.0.1` 并重启 HydroOJ |
| 管理员进不了比赛管理 | 未获得 `gw_admin` Cookie | 先登录 `/exam/admin`，再登录 HydroOJ |
| 教师截图失败 | 学生机 34519 被防火墙拦截 | 加 Windows 防火墙入站规则 |
| 学生端提示指纹不匹配 | 修改过客户端或换了新包 | 运行 `allowlist.py` |
| 学生端一直报“能上网” | WAN 未断或学生机连了手机热点 | 检查路由器 WAN、学生机网络 |
| `/websocket 404` 日志 | 网关未实现 WebSocket 代理 | 不影响当前登录/录像，但实时通知会降级 |
| `python3 -m venv` 权限错误 | 用了 `/root/.nix-profile/bin/python3` 创建 venv | 用 `/usr/bin/python3 -m venv .venv` |
| 学生机无法登录 | 账号未报名/比赛未开始/账号错误 | 检查比赛权限、账号和时间 |

## 10. 安全检查

- [ ] HydroOJ 只监听 `127.0.0.1:8889`
- [ ] 学生无法访问 `8889`
- [ ] 路由器 WAN 不接互联网
- [ ] 学生机无法访问外网
- [ ] `server/.env` 权限为 `600`
- [ ] `server/keys/private.pem` 权限为 `600`
- [ ] 不把 `.env` 和私钥发给学生
- [ ] 学生端截图接口未登录返回 401
- [ ] 伪造 `X-Forwarded-For` 不能绕过教师 JWT
- [ ] 客户端修改后已重算白名单
- [ ] 教师控制台密码不是默认值
- [ ] 路由器 AP 隔离已关闭，访问控制未误拦 NUC

## 12. 应急处理

### 12.1 网关崩溃

```bash
sudo systemctl restart ckyf-exam-gateway
sudo journalctl -u ckyf-exam-gateway -n 200 --no-pager
```

### 12.2 HydroOJ 崩溃

```bash
sudo pm2 list
sudo pm2 restart hydrooj
sudo pm2 logs hydrooj --lines 200
```

### 12.3 比赛 URL 写错

```bash
nano /home/ckyf/ctest/exam-system/server/.env
# 修改 CKYF_CONTEST_URL
sudo systemctl restart ckyf-exam-gateway
```

### 12.4 忘记监考密码

```bash
grep '^CKYF_ADMIN_PASSWORD=' /home/ckyf/ctest/exam-system/server/.env
```

如果文件被误删，重新设置一个：

```bash
python3 -c 'import secrets; print(secrets.token_urlsafe(24))'
nano /home/ckyf/ctest/exam-system/server/.env
sudo systemctl restart ckyf-exam-gateway
```
