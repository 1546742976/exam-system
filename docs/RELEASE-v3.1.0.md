# v3.1.0 — Windows 单文件考试客户端

下载 CKYF-Exam-3.1.0-x64.exe，连接 NUC 考试热点后双击启动，无需安装 Python、无需解压目录。默认接口地址 10.42.0.1:8888，填写考试账号密码即可登录。

运行环境：Windows 10/11 x64，须有 Microsoft Edge WebView2 Runtime；离线考场应在考前完成运行环境安装。单 EXE 内置 Python、依赖、前端和公钥，但不内置系统 WebView2 Runtime。

首次运行会自动解包到用户缓存。录像和日志保存在 %LOCALAPPDATA%\CKYF\Exam，不会随临时解包目录清理。每台建议至少预留 3 GB，开考前归档上次考试录像；日志目录下可查看启动失败原因。

包含此前鉴权、上传路径隔离、指纹校验、有界上传队列、上传重试和录像 Range 修复。服务端须使用配套版本及匹配公钥的私钥。主程序版本 3.1.0.0。

验证边界：本机单文件资源/依赖自检、项目回归和假 OJ 冒烟；110 人模拟心跳/上传不代表真实热点容量。尚未完成 NUC 110 台无线设备、超过 3 小时真实考试的实机验收。
