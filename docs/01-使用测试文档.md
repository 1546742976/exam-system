# 考试系统使用与测试文档

> 适用：`exam-system/client`（Windows 学生端）、`exam-system/server`（考试网关）、`exam-system/addon`（HydroOJ 插件）。
> 服务端运行环境：Ubuntu NUC；学生端：Windows 10/11 x64。

---

## 1. 网络拓扑与端口

```text
校园 Wi-Fi（管理网，NUC wlo1）
        │
        │  仅用于管理员维护 NUC，不转发给学生
        ▼
      NUC
  ┌───────────────┐
  │ enp88s0       │  10.20.0.x/24
  │ exam gateway  │  0.0.0.0:8888
  │ HydroOJ       │  127.0.0.1:8889（只允许本机访问）
  └───────────────┘
        │
        │ 网线
        ▼
  比赛路由器 LAN 口（10.20.0.1）
        │
        ├── 学生机 10.20.0.100+
        └── 教师机（可选）
```

| 服务 | 监听地址 | 说明 |
|---|---|---|
| 考试网关 | `0.0.0.0:8888` | 学生访问入口 |
| HydroOJ | `127.0.0.1:8889` | **只能本机访问**，防止学生绕过网关 |
| 学生客户端本地服务 | 学生机 `0.0.0.0:34519` | 教师抓图/抽查使用，需 JWT |
| 路由器 LAN | `10.20.0.1/24` | DHCP 网关 |

学生浏览器/客户端统一使用：

```text
http://<NUC 的 10.20.0.x 地址>:8888/
```

当前实际地址示例：

```text
http://10.20.0.105:8888/
```

> 建议在路由器里按 NUC 的 MAC `48:21:0B:2D:1D:95` 做 DHCP 静态绑定，
> 或者在 NUC 上给 `enp88s0` 配静态地址，避免地址变化。

## 2. 服务端部署（NUC）

### 2.1 安装依赖

```bash
cd /home/ckyf/ctest/exam-system/server
/usr/bin/python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

如果系统提示缺少 `ensurepip`：

```bash
sudo apt install python3-venv
```

> 注意：如果 `python3` 指向 `/root/.nix-profile/bin/python3`，不要用它创建供 `ckyf`
> 用户运行的 venv，否则 `ckyf` 可能没有权限执行 `/root` 下的解释器。
> 请显式使用 `/usr/bin/python3 -m venv .venv`。

### 2.2 生成运行密钥

```bash
cp .env.example .env
python - <<'PY'
import secrets
print('admin =', secrets.token_urlsafe(24))
print('session =', secrets.token_urlsafe(48))
print('sign_key =', secrets.token_urlsafe(32))
PY
```

把生成的值写入 `server/.env`：

```text
CKYF_ADMIN_PASSWORD=管理员口令
CKYF_SESSION_SECRET=会话随机密钥
CKYF_SIGN_KEY=视频切片共享密钥
CKYF_HOST=0.0.0.0
CKYF_PORT=8888
CKYF_UPSTREAM=http://127.0.0.1:8889
CKYF_TRUST_PROXY_HEADERS=false
```

注意事项：

- `CKYF_SIGN_KEY` 必须与 `client/config.json` 里的 `sign_key` 一致；
- 默认 `CKYF_TRUST_PROXY_HEADERS=false`。只有网关确实在 Caddy/Nginx 后面时才改成 `true`，否则学生可伪造来源 IP；
- `.env` 不要发给学生，也不要上传公开仓库。

### 2.3 调整 HydroOJ 端口

HydroOJ 必须只监听本机 8889，不能让考场学生直接访问 8889。

需要把 HydroOJ 的监听设置改为：

```text
server.host = 127.0.0.1
server.port = 8889
```

可以通过 HydroOJ 的系统设置修改，或者给启动命令增加：

```text
--host 127.0.0.1 --port 8889
```

修改后重启 HydroOJ，并验证：

```bash
curl -I http://127.0.0.1:8889/
ss -lnt | grep 8889
```

期望看到：

```text
LISTEN 127.0.0.1:8889
```

不能看到：

```text
LISTEN 0.0.0.0:8889
```

### 2.4 安装 HydroOJ 插件

把 `exam-system/addon` 安装到 HydroOJ 的 addon 目录，**目录名必须是 `exam`**，否则 `/exam/*`、`/exam/assets/*` 会 404。

在 HydroOJ 后台插件配置中设置：

```text
contestId          = 你的比赛 ID
clientDownloadUrl  = /exam/ckyf_exam.zip
privateKeyFile     = /home/ckyf/ctest/exam-system/server/keys/private.pem
```

`privateKeyFile` 必须指向服务端私钥文件。插件私钥不再写死在源码中。

安装后验证：

```bash
curl -I http://127.0.0.1:8889/exam
```

不应返回 404。

### 2.5 启动考试网关

```bash
cd /home/ckyf/ctest/exam-system/server
. .venv/bin/activate
python gateway.py
```

启动日志应类似：

```text
考试网关启动: http://0.0.0.0:8888  ->  上游 http://127.0.0.1:8889
```

验证：

```bash
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8888/exam/admin
```

期望 `200`，页面标题为“监考控制台”。

> HydroOJ 插件路由是 GET-only。用 `curl -I` 发 HEAD 请求时看到
> `405 Method Not Allowed` 是正常的，不是插件未加载。

### 2.6 可选：使用 80 端口

当前 Caddy 已监听 80。如果希望学生只输入：

```text
http://10.20.0.105/
```

可将 Caddy 反向代理目标改为 `127.0.0.1:8888`。但直接使用 `:8888` 更容易排查问题，建议正式测试先统一使用 `:8888`。

## 2.7 管理员管理比赛

考试网关默认会拦截所有包含 `/contest` 的 URL，防止学生直接访问。管理员需要先取得
网关管理员 Cookie，再进入 HydroOJ 管理比赛：

1. 打开 `http://<NUC_IP>:8888/exam/admin`，输入 `server/.env` 中的
   `CKYF_ADMIN_PASSWORD`；
2. 在同一浏览器打开 `http://<NUC_IP>:8888/`，登录 HydroOJ 管理员账号；
3. 此时再进入比赛列表或创建比赛，网关会识别 `gw_admin` Cookie 并放行。

如果暂时不想走网关，也可以在 NUC 本机浏览器直接打开
`http://127.0.0.1:8889/` 管理 HydroOJ。

## 3. 学生客户端部署（Windows）

### 3.1 环境要求

- Windows 10 1809+ / Windows 11，x64；
- 安装 WebView2 Evergreen Runtime x64；
- 建议 Python 3.12 / 3.13，不建议 3.14；
- 每台机器至少预留 2 GB 磁盘。

### 3.2 安装依赖

```bat
cd client
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python main.py
```

客户端启动后填写：

```text
接口地址：10.20.0.105:8888
考试账号：HydroOJ 账号
```

然后依次完成：

1. 登录；
2. 环境检测；
3. 选择屏幕和摄像头；
4. 点击下一步进入考试页。

## 4. 测试清单

### 4.1 服务端自动测试

```bash
cd /home/ckyf/ctest/exam-system/server
. .venv/bin/activate

python tools/smoke_test.py
python tools/net_check.py --expect 10.20.0.0/24 --gw 10.20.0.1 --peers 10.20.0.101
python tools/allowlist.py ../client
```

`smoke_test.py` 应输出：

```text
结果：16/16 通过
```

`allowlist.py` 会重新计算客户端指纹。只要改过 `client/*.py` 或客户端公钥，就必须重新执行。

### 4.2 学生机网络测试

学生机连接比赛路由器后执行：

```text
ipconfig
```

确认：

```text
IPv4 地址：10.20.0.xxx
子网掩码：255.255.255.0
默认网关：10.20.0.1
```

然后：

```text
ping 10.20.0.1
ping 10.20.0.105
curl.exe -I http://10.20.0.105:8888/exam/admin
```

期望：

- 能 ping 通网关；
- 能 ping 通 NUC 考试网地址；
- 网关控制台返回 200。

外网必须不通：

```text
ping 223.5.5.5
curl.exe -I https://www.baidu.com --max-time 5
```

期望失败或超时。若学生机还能访问外网，检查：

- 路由器 WAN 是否拔掉；
- 路由器是否开启了 IPv6；
- 学生机是否还连着手机热点/其他 Wi‑Fi。

### 4.3 禁止绕过网关

学生机直接测试 HydroOJ 内部端口：

```text
Test-NetConnection 10.20.0.105 -Port 8889
```

期望 `TcpTestSucceeded : False`。如果为 True，说明 HydroOJ 绑定到了 `0.0.0.0`，必须改为 `127.0.0.1`。

### 4.4 客户端本地服务安全测试

在学生机本机或局域网另一台电脑上测试（把 `<学生IP>` 替换为实际地址）：

```powershell
curl.exe -i http://<学生IP>:34519/screenshot/latest
```

期望返回 `401`，不能直接拿到屏幕截图。

伪造来源 IP：

```powershell
curl.exe -i -H "X-Forwarded-For: 127.0.0.1" http://<学生IP>:34519/recorder/list
```

期望仍返回 `401`。

### 4.5 端到端功能测试

1. 学生端登录成功；
2. 选择屏幕和摄像头后开始录像；
3. 教师打开：
   ```text
   http://10.20.0.105:8888/exam/admin
   ```
   能看到该学生在线、IP、心跳和指纹；
4. 客户端本地录像目录出现 `video_*.ts` 和 `.sig`；
5. 监考控制台“截图”能返回当前屏幕；
6. “抽查”返回带随机码的截图；
7. 学生端断网/异常探测能生成告警；
8. 服务端 `server/data/uploads/日期/账号/` 出现上传文件；
9. 控制台能看到上传数量和缺口统计；
10. 考试结束后用 `tools/verify_sig.py` 校验录像切片签名。

## 5. 比赛当天开考流程

1. NUC 启动考试网关和 HydroOJ；
2. 检查 `enp88s0` 地址和路由：
   ```bash
   ip -4 addr show enp88s0
   ip route
   ```
   默认路由应只走 `wlo1`；`10.20.0.0/24` 走 `enp88s0`；
3. 路由器 WAN 不接外网；
4. 学生机连接比赛 Wi‑Fi 或有线局域网；
5. 教师控制台确认所有学生在线；
6. 学生端完成设备检查并进入考试；
7. 考试过程中使用控制台查看在线、静默、告警、上传缺口和抽查；
8. 结束后停止客户端、关闭网关，备份：
   ```text
   server/data/exam.db
   server/data/uploads/
   client/media/
   ```

## 6. 常见问题

### 学生访问不了 10.20.0.105:8888

按顺序检查：

1. 学生机和 NUC 是否都在 `10.20.0.0/24`；
2. `ping 10.20.0.1` 是否通；
3. 路由器是否开启了 AP 隔离/访问控制；
4. 网关是否监听 `0.0.0.0:8888`；
5. 防火墙是否放行 TCP 8888。

### 网关启动失败：缺少生产密钥

检查 `server/.env` 是否存在，且：

```text
CKYF_ADMIN_PASSWORD
CKYF_SESSION_SECRET
CKYF_SIGN_KEY
```

都不是空值，也不包含 `CHANGE_ME`。

### `/exam` 返回 404

检查：

- addon 目录名是否为 `exam`；
- HydroOJ 是否加载了插件；
- `privateKeyFile` 是否指向有效的私钥文件。

### 学生在线但教师抓图 401/403

检查：

- 教师令牌是否由网关 `/exam/admin/api/token` 生成；
- 学生机 34519 是否可达；
- 客户端 JWT 公钥是否与网关私钥匹配。

---

## 7. 安全注意事项

- 不要把 `server/.env`、`server/keys/private.pem` 发给学生；
- 不要把 HydroOJ 的 8889 端口暴露到局域网；
- 默认不要开启 `CKYF_TRUST_PROXY_HEADERS`；
- 每次正式考试前重新生成管理员口令和会话密钥；
- 修改客户端 Python 文件后必须重新运行 `allowlist.py`；
- 客户端录像是证据文件，考试结束后先备份再清理。
