> 参数和校验脚本速查。完整部署与开考流程请优先阅读 `docs/01-使用测试文档.md`。

## 0. 五步速览

| 步骤 | 谁做 | 产出 |
|---|---|---|
| ① 核验 NUC 热点 | 管理员 | 考场 WiFi + `<实际热点网段/前缀>` |
| ② 装服务端 | 管理员（NUC） | 网关 `http://<NUC_LAN_IP>:8888` |
| ③ 装客户端 | 每台学生机 | 窗口能打开登录页 |
| ④ 调参数 | 管理员 | 按考场规模改 `config.json` |
| ⑤ 跑校验 | 管理员 | 全 PASS 才开考 |

## 1. 热点地址

NUC 热点：`10.42.0.1`；学生填写 `10.42.0.1:8888`。
子网前缀、DHCP 范围、SSID 与密码以实机配置为准，不预设 /24 或地址池。

## 2. NUC 自身热点

按 [热点部署与验收](03-NUC热点部署与验收.md) 检查已有热点，不再使用外置路由器。
考试期间 NUC 和学生全部离线。保留当前可用热点，不重建连接。

## 3. 服务端（NUC）

```bash
cd server
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env：填入管理员口令、会话密钥、sign_key
python gateway.py            # http://0.0.0.0:8888 -> 上游 127.0.0.1:8889
```

**生产密钥**：不要写进 `config.json`。
- `server/.env` 保存管理员口令、会话密钥、切片 `sign_key`；
- HydroOJ 插件通过 `exam.privateKeyFile` 读取 `server/keys/private.pem`；
- 公钥在 `server/keys/public.pem` + `client/keys/public.pem`；
- `sign_key` 必须与 `client/config.json` 一致。

**NUC 网络**：保留现有 `10.42.0.1` 热点，按热点验收手册核实接口与前缀。

**开机自启（systemd 示例）**：

```ini
[Unit]
Description=ckyf exam gateway
After=network-online.target
Wants=network-online.target

[Service]
User=ckyf
Group=ckyf
WorkingDirectory=/home/ckyf/ctest/exam-system/server
EnvironmentFile=/home/ckyf/ctest/exam-system/server/.env
ExecStart=/home/ckyf/ctest/exam-system/server/.venv/bin/python gateway.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## 4. 客户端（学生机）

```bat
cd client
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python main.py
```

- 只支持 **Windows 10 1809+ / 11，x64**；
- Win10 **必须装 WebView2 Evergreen Runtime（x64）**，否则白屏；
- Python 用 **3.12 / 3.13**（3.14 可能缺 `av`/`opencv` 轮子）；
- 启动时会自检系统版本 + WebView2，不满足直接报错退出。

学生填：接口地址 `10.42.0.1:8888` + 考试账号。流程：登录 → 环境检测 → 选屏幕+摄像头 → 下一步 → 进考试页。

打包：`build_nuitka.bat`（推荐）或 `build_pyinstaller.bat`，产物是**整个文件夹**。
**改过 `client/*.py` 必须重算指纹**：

```bat
cd server
python tools/allowlist.py ../client
```

## 5. 参数设置

### 5.1 客户端 `client/config.json`

**画质与磁盘**

| 参数 | 默认 | 含义 | 3 小时/80 人建议 |
|---|---|---|---|
| `fps` | `2` | 录像帧率 | 2 |
| `capture_scale` | `0.5` | 分辨率缩放 | 0.5（2560→1280 宽） |
| `screen_bitrate_kbps` | `300` | 屏幕码率 | 磁盘紧→200 |
| `camera_bitrate_kbps` | `100` | 摄像头码率 | 60 |
| `segment_seconds` | `10` | 切片长度 | 10 |
| `max_stream_mb` | `1200` | **单路磁盘上限**，超出删最老切片 | 800 |
| `muxer` | `segment` | 自己切段（推荐） | 保持 |

**检测项**

| 参数 | 默认 | 含义 |
|---|---|---|
| `enabled_monitors` | `["ai","vm","net"]` | ai=本地AI / vm=虚拟机 / net=外网 / mem / vram / lan / hotspot |
| `monitor_interval` | `10` | 检测间隔（秒） |
| `ai_scan_models` | `true` | 是否扫本地模型文件 |
| `ai_model_dirs` | `.ollama/models` 等 | 模型目录 |
| `net_probe_urls` | `["https://www.baidu.com"]` | 断网考场保持默认；必须联网则清空 `[]` |

**上传与鉴权**

| 参数 | 默认 | 含义 |
|---|---|---|
| `upload_mode` | `keyframes` | 只传关键帧（≈0.024Mbps/人）/ `segments` 传整片 |
| `keyframe_interval` | `30` | 关键帧间隔（秒） |
| `port` | `34519` | 本地面板端口，**别改** |
| `jwt_public_key_file` | `keys/public.pem` | 与插件同一把公钥 |
| **`jwt_audience`** | **`""`** | **插件令牌没有 aud，必须留空** |
| `sign_key` | 与 server 一致 | 切片签名 |

### 5.2 服务端 `server/config.json`

| 参数 | 默认 | 含义 |
|---|---|---|
| `port` | `8888` | 学生填的端口 |
| `upstream` | `http://127.0.0.1:8889` | **HydroOJ 真实地址** |
| `contest_url` | `/d/system/contest/` | 考试页前缀 |
| `admin_password` | 生成值 | 控制台口令 |
| `gate_enabled` | `true` | 是否要求考试上下文 |
| `login_concurrency` | `16` | 打向 OJ 的登录并发；OJ 弱→8 |
| `async_db` | 兼容旧配置 | 登录审计直接落库，不再依赖会丢事件的后台队列 |
| `silence_seconds` | `40` | 多久没心跳判静默 |
| **`force_client_ua`** | `exam-client/2.0` | 转发时补 UA，避免插件门禁 403 |
| `student_port` | `34519` | 教师抓图访问学生机的端口 |
| `sign_key` | 与客户端一致 | 切片签名 |

## 6. 与 HydroOJ 插件（addon）集成

| 事项 | 说明 |
|---|---|
| 安装目录名 | **必须是 `exam`**，否则插件的 `/exam/assets/*`、`/exam/ckyf_exam.zip` 全 404 |
| 门禁原理 | 插件在 `handler/after/ContestList/ContestDetail` 里判定：UA 含 `exam-client` 或 uname 以 `_ncec` 结尾或教师权限 → 放行，否则 **403** |
| 为什么要网关补 UA | WebView 的 UA 是 Edge，不含 `exam-client`；网关在 `_forward()` 里统一改写 |
| 告警格式 | 插件用 `@param('alerts', Types.Content)`，要求 `alerts` 是**二次编码的 JSON 字符串**；客户端已按此发送，网关也兼容数组 |
| 令牌 | 插件 `/exam/token` 与网关 `/exam/admin/api/token` 都用同一把私钥签 RS256 |
| 私钥 | 插件私钥不在源码中，必须通过 `exam.privateKeyFile` 或 `CKYF_EXAM_PRIVATE_KEY_FILE` 指向 `server/keys/private.pem` |

## 7. 校验脚本（都在 `server/tools/`）

| 脚本 | 用途 | 通过标准 |
|---|---|---|
| `smoke_test.py` | 服务端冒烟（内置假 OJ，16 项） | **16/16** |
| `allowlist.py` | 重算客户端指纹白名单 | 控制台不再报"指纹不匹配" |
| `net_check.py` | 考场连通性 + 学生机 34519 | 全 PASS、外网不通 |
| `port_scan.py` | 考中端口巡检 | 只出现 34519 |
| `verify_sig.py` | 考后切片签名校验 | 逐片 OK |

```bash
cd server
. .venv/bin/activate
python tools/smoke_test.py
python tools/allowlist.py ../client
python tools/net_check.py --expect "$EXAM_CIDR" --gw 10.42.0.1 --peers "$STUDENT_IP"
python tools/port_scan.py <实际热点网段/前缀>
python tools/verify_sig.py "../client/media/Recorder.Display1 (2560x1600)" zhangsan "<sign_key>"
```

## 8. 开考清单

- [ ] WAN 拔线、IPv6 关、固件自动升级关
- [ ] `net_check.py` 全 PASS；学生机实测外网不通
- [ ] NUC 固定 IP，考试网关 `8888` 在监听，HydroOJ 只监听 `127.0.0.1:8889`
- [ ] `smoke_test.py` 16/16
- [ ] `allowlist.py` 已重算
- [ ] 每台机 WebView2 已装、能开到登录页
- [ ] 磁盘每台 ≥ 2 GB
- [ ] 学生**分批登录**（每批 20 人，间隔 30–60 秒）

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 学生登录一直转圈 | 登录风暴 → 分批放行；`login_concurrency` 调 8 |
| 全部机器报"能上网" | WAN 还连着 → 拔线，或清空 `net_probe_urls` |
| 客户端白屏 | 没装 WebView2（Win10）或 `static/` 不在同级目录 |
| 考试页 403 | 从 `/d/...` 直链进 → 必须走客户端"下一步" |
| 指纹全不匹配 | 改过客户端代码 → 跑 `allowlist.py` |
| 教师看不到屏幕 | 开了 AP 隔离 → 教师机改有线 |
